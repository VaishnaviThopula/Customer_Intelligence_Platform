# AI-Powered Customer Intelligence Platform
## Project Overview
A customer intelligence application for analysing
healthcare customer support tickets using Python,
SQL, Machine Learning and Generative AI.
## Objectives
- Customer complaint analysis
- Ticket classification
- Priority prediction
- Sentiment analysis
- AI-powered knowledge retrieval
- Business intelligence dashboard
## Technology Stack
Python, Pandas, SQL, Scikit-learn,
FastAPI, RAG, LLMs, Power BI and AWS.
